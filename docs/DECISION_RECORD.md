# Decision record

This file condenses the public decisions that shape the repository. It intentionally excludes internal review transcripts and operational ledgers.

## DR-001: Validate first

**Status:** Active

Flow Lens is an experimental local portfolio preview. Product need, user behavior, real-video feasibility, correction burden, and stable improvement are not validated. Public availability does not upgrade that evidence.

## DR-002: Narrow scenario, not a validated persona

**Status:** Active

The current scenario is one owner-operator, one fixed workstation, and repeated packing of the same SKU. This is a falsifiable design and research cut, not a proven beachhead, market denominator, or employee workflow.

## DR-003: Manual and synthetic before automation

**Status:** Active

The complete default path uses a deterministic programmatic source and manual review. A removable `NullAdapter` represents the model boundary. No CV, AI recommendation, tracking, pose estimation, 2.5D, or 3D is implemented.

## DR-004: Evidence chain is non-negotiable

**Status:** Active

Only active `confirmed` or `edited-final` observations can enter metrics. Coverage, current zone geometry, exact source identity, immutable revisions, and rule versions remain traceable. Unknown evidence is never converted to zero.

## DR-005: Differences are descriptive, not causal

**Status:** Active

Before/After output requires exact comparison gates and always uses `attribution: not-established`. The interface must not claim improvement, efficiency, savings, best layout, or cause. The user authors one reversible change and chooses keep, revert, or uncertain.

## DR-006: Local media is a limited source viewer

**Status:** Active

Optional local files use session-only object URLs, one source per phase, with no upload, persistence, extraction, or cloud fallback. User-provided provenance remains unverified. Local 1+1 cannot complete the guided 3+3 experience.

## DR-007: No employee monitoring or private-data workflow

**Status:** Active

The project does not support employee ranking, disciplinary output, covert recording, ergonomics, medical, or safety scoring. Issues and pull requests must use synthetic reproductions and must not attach real employees, customers, orders, addresses, voices, or private video.

## DR-008: Public experimental baseline under MIT

**Status:** Active

The allowlisted code, public documentation, generated fixture, provenance record, and selected synthetic screenshots are released under MIT as an experimental local portfolio preview. Raw internal reviews, manifests, audit output, and local environment material are not part of the public repository.

## Open questions

- Can an unfamiliar person understand the interface without guidance?
- Does the target problem exist strongly enough to justify recording and correction effort?
- Can any real-data path ever meet rights, host-security, deletion, and misuse requirements?
- Is software better than ordinary video plus a manual review protocol?

Until those questions have evidence, the appropriate conclusion remains **Validate first**.
