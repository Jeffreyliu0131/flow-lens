# Known limitations

- The need, target user, natural reuse, willingness to record/correct/re-record, and business value are not validated.
- The fixed-workstation, owner-operator, same-SKU scenario is a narrow research hypothesis, not a proven market segment or persona.
- All default sources, events, and comparison values are synthetic examples.
- There is no computer vision, AI analysis, automatic action understanding, 2.5D, 3D, or recommendation engine.
- Local video is a session-only source viewer with one file per phase. It cannot complete the guided 3+3 comparison.
- Coverage finalization is a prototype user assertion, not double annotation, agreement measurement, or a missed-event audit.
- Before/After differences are descriptive. Practice, observation, input variation, and visibility remain alternative explanations.
- State is in memory. There is no persistence, collaboration, import migration, export, purge receipt, backup control, or production rollback system.
- Automated coverage targets Chromium desktop/mobile. Axe and keyboard checks are not a complete assistive-technology or browser certification.
- The current Radix bundle is intentionally retained for this preview and is larger than a production target should be.
- There is no production host, threat model, support SLA, rights workflow, pricing model, deployment, or public service.

Do not describe Flow Lens as demand validated, accurate on real video, privacy compliant, securely deleting files, causally improving a workflow, production ready, or an approved product architecture.
