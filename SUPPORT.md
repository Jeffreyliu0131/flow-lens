# Support

Flow Lens is an experimental portfolio preview maintained on a best-effort basis. There is no production support SLA.

## Usage questions and bugs

Use GitHub Issues after checking existing reports. Include:

- the commit SHA;
- Node.js and browser versions;
- the exact command or guided step;
- expected and observed behavior;
- a minimal synthetic reproduction;
- console output with secrets and local absolute paths removed.

Do not upload real employees, customers, orders, addresses, voices, private video, or confidential workflow material.

## Security issues

Follow [SECURITY.md](SECURITY.md) and use a private security advisory. Do not post exploit details publicly.

## Out of scope

The project does not provide advice or support for employee monitoring, ergonomics, medicine, safety, disciplinary decisions, real-person research, production deployment, or causal workflow optimization.
